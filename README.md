# Redx ID Maker

An Android app that generates realistic ID card images for 10+ countries, including passports, driver's licences, national ID cards, and business documents.

## Features
- 🌍 10+ countries: Nigeria, UK, USA, Ghana, Kenya, South Africa, India, Canada, Australia
- 🪪 Multiple ID types per country
- 📖 Passport open-book spreads with MRZ
- 🏢 Business documents: Certificate of Incorporation, Employee ID, Business Registration, Letter of Introduction
- 💾 Save generated IDs to phone gallery

## Build
```
./gradlew assembleDebug
```

APK will be in `app/build/outputs/apk/debug/`
